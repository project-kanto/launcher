# Security

Do not report credential exposure or update-signing vulnerabilities in a public issue. Contact the
Kanto maintainers privately through the security contact published on the official Kanto website.

Kanto Launcher must never transmit Apple passwords, authentication sessions, signing keys,
certificates, provisioning profiles, Discord tokens, device identifiers, or client archives to
Kanto. Release downloads are accepted only after their size and SHA-256 digest match the signed
release metadata.
